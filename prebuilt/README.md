# prebuilt/ — 成品幻灯片

放**现成的幻灯片成品**的地方：用其它工具做好的幻灯片（主要是 PDF，也可以是
PPT / PPTX），不是用 Typst 写的、也不经过编译，放进这个仓库里**留存和展示**。
把文件丢进这个目录、推送到 `main`，GitHub Actions 就会把它原样发布到站点，
并在首页单独列一个「成品幻灯片」区块（与 Typst 幻灯片分开）：

- 在线打开：`https://tortrixx.github.io/slides/prebuilt/<文件名>`
- 每次按日期发的 Release 里也会带上这些文件作为附件。

## 约定

- **只放 `.pdf` / `.ppt` / `.pptx`**（扩展名大小写不限，以 PDF 为主）。
  其它文件构建会直接报错。
- **文件名**会成为 URL 的一部分，规则与幻灯片文件夹名一致：汉字 / 字母 / 数字 /
  点 / 下划线 / 连字符，不要空格和其它符号，不要以点开头。
- **单个文件 ≤ 100 MB**（GitHub Pages 的单文件上限，超了构建会报错）。
- 排序与「最近更新」圆点和 Typst 幻灯片同口径：按该文件最后一次提交的时间，新在前。

## 给文件配标题和说明（可选）

默认卡片标题就是文件主名。想给个正经标题，放一个**同名旁车文件**：

```
prebuilt/
├── 开题答辩.pdf
└── 开题答辩.md      ← 第一行是标题，其余行是说明
```

旁车内容示例：

```
开题答辩：多模态检索系统设计
用 Beamer 做的版本，留存展示。
```

PDF / PPTX 若自带文档标题（元数据里的 Title），没旁车时会自动用它当标题；
PPT 是老二进制格式、读不到元数据，只能靠旁车或文件名。

> 本文件（README.md）与旁车 `.md` 本身不会被发布。
